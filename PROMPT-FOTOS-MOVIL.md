# Estrategia móvil vigente

Las seis imágenes móviles están generadas desde las tres panorámicas existentes: dos grupos de tres modelos por color, de 836 × 941 píxeles. El prompt anterior para 18 fotos individuales ya no se utiliza.

Ejecuta `npm run images` para regenerarlas y `npm run build` para compilar. La versión de PC permanece intacta. Consulta `README.md` para más detalles.
